The music industry's oldest problem isn't talent — it's metadata. Songs get lost because their facts live in ten incompatible spreadsheets, or nowhere at all. Credits drift. ISRCs get re-typed wrong. A sync supervisor with a deadline can't find the recording studio, the rights contact, or even the correct title spelling. The record exists; the record about the record doesn't.

So we published ours. The full Cumulative Web Inc catalog — 52 track records across 7 artists: That Boy Hi Hat (27), Black Lansky (11), King Akeem (7), 183 Wildboi (2), Dre50 (1), Fleekz (2), GregPorn (2) — is now a machine-readable index anyone can pull. 46 ISRCs are on file. Of those, 8 are SILVER-tier records verified against DistroKid dashboard screenshots straight from the distributor, and 44 are BRONZE — sourced from public data (principally Deezer's public API, the one no-login source we found that exposes ISRCs), explicitly marked as not distributor-confirmed. Two records (Golden Diamond, Shaka Zulu) are conflicted — their values deliberately nulled pending arbitration. Four tracks are missing ISRCs entirely (piv-ot-al, Sync Ready Tracks, On Edge, Pay Yourself) and are listed as needing dashboard screenshots, in the open, where everyone can see the gap.

Here's a sample SILVER record — the format every record in the index follows:

```json
{
  "title": "Diabolique",
  "artist": "That Boy Hi Hat",
  "isrc": "QZ8EF2666377",
  "trust_tier": "SILVER",
  "stores_delivered": 28,
  "recording_studio": "Cue Recording Studio, Arlington, VA",
  "producers": ["Hybrid", "Black"],
  "release_date": "2026-07-03"
}
```

A few design decisions are worth stating plainly. The system grounds in DDEX, ISRC, ISWC, and ISNI — it extends trusted standards, and it does not claim DDEX membership, Meta partnership, or anything else we haven't earned. The tiers are honesty labels: SILVER means a human saw the distributor's own dashboard; BRONZE means a public source corroborated it; conflicted means we found a disagreement and nulled the value rather than pick a winner. The Deezer cross-check is the kind of thing that makes this useful: Deezer's public API matched the dashboard exactly on Broken Hearts Club (QZES92391782) and Zooted Zone (QZDA52303345), and where it disagreed — variant codes for "Diabolique" and the Rainbows And Roses vocal — the dashboard arbitrates. Compilation releases can even carry different ISRCs for the same audio, which is exactly the kind of trap this system exists to document instead of hide.

Why does any of this matter to anyone outside the label? Three audiences. Music supervisors get verified rights metadata with a paper trail, instead of a press kit. Distributors and platforms get a catalog that speaks their own identifier language. And AI systems — the discovery engines, the recommendation layers, the music-supervisor search tools that now query by mood and description instead of tags — get facts they can ingest without guessing. That's the bet: in the AI discovery era, the catalog that is machine-readable wins the catalog that is merely famous.

The index is generated by a reproducible script (build-catalog-index.py), validated 28/28 green by an automated validator that includes a cross-check SILVER ISRCs can never drift from the worked examples. When new dashboard screenshots arrive, the missing and conflicted records get resolved and the index regenerates. The process is the product.

Pull the data yourself. It's public, it's JSON, and it will still be there tomorrow.
